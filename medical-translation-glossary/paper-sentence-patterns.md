# 医学论文常见句式

| English pattern | 推荐译法 |
| --- | --- |
| The aim of this study was to... | 本研究旨在…… |
| We conducted a randomized trial to evaluate... | 我们开展了一项随机试验，以评估…… |
| Patients were randomly assigned to... | 患者被随机分配至…… |
| The primary endpoint was... | 主要终点为…… |
| Compared with placebo,... | 与安慰剂相比，…… |
| The results should be interpreted with caution. | 应谨慎解释这些结果。 |
| These findings suggest that... | 这些发现提示…… |
| Further studies are needed to... | 仍需进一步研究以…… |

## Translation Notes

- `suggest` 在论文里多数时候更适合译为“提示”，不要直接译成“证明”。
- `may`、`might`、`could` 要保留不确定性。
- `associated with` 通常表示相关，不一定表示因果。

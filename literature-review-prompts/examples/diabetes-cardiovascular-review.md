# 示例：2 型糖尿病与心血管结局综述

## 研究问题

GLP-1 受体激动剂和 SGLT2 抑制剂对 2 型糖尿病患者心血管结局的影响有何差异？

## PICO

| 元素 | 内容 |
| --- | --- |
| P | 2 型糖尿病患者，尤其是合并心血管疾病或高危因素的人群 |
| I | GLP-1 receptor agonists 或 SGLT2 inhibitors |
| C | 安慰剂、标准治疗或其他降糖药 |
| O | MACE、心血管死亡、心衰住院、全因死亡、肾脏结局 |

## 检索关键词

- Type 2 diabetes mellitus
- GLP-1 receptor agonists
- SGLT2 inhibitors
- cardiovascular outcomes
- major adverse cardiovascular events
- heart failure hospitalization

## 综述大纲

1. 2 型糖尿病心血管风险概述
2. GLP-1RA 的心血管结局证据
3. SGLT2 抑制剂的心血管和心衰证据
4. 两类药物在不同患者亚群中的适用场景
5. 指南推荐和真实世界研究
6. 研究空白：直接头对头比较、长期安全性、合并 CKD/心衰人群

## 需要核查

- 每个药物对应的心血管结局试验。
- 主要终点定义是否一致。
- 是否存在亚组分析过度解读。
- 指南推荐年份和证据等级。

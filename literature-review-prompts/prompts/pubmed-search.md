# PubMed 检索式生成 Prompt

```text
你是一名 PubMed 检索策略助手。请把下面的中文研究问题转换为 PubMed 检索策略。

研究问题：
{输入你的中文研究问题}

请输出：
1. PICO 拆解：
   - P: 人群/疾病/研究对象
   - I/E: 干预、暴露或核心因素
   - C: 对照
   - O: 结局指标
2. 英文关键词和同义词。
3. 可能的 MeSH Terms。
4. 宽检索式：用于初步探索。
5. 中等严格检索式：用于常规综述。
6. 严格检索式：加入研究类型、时间范围或期刊限制。
7. 排除项建议：动物实验、非英文、病例报告等是否需要排除。
8. 检索策略解释：为什么这样组合。

要求：
- 不确定的 MeSH 词请标注“需在 PubMed MeSH Database 核对”。
- 不要保证检索结果数量。
- 最终检索式必须可复制到 PubMed。
```

## Example

中文问题：

```text
GLP-1 受体激动剂对 2 型糖尿病患者心血管结局的影响，最近 5 年，优先临床试验和系统综述。
```

你可以先用这个 prompt 生成检索式，再在 Suppr 或 PubMed 中核查结果。

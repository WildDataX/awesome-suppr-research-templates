# 文献综述 Prompt

复制下面的 prompt，把 `{研究主题}`、`{学科方向}` 和 `{目标读者}` 替换成你的内容。

```text
你是一名严谨的医学/科研文献综述助手。请围绕主题「{研究主题}」设计一份文献综述写作框架。

背景：
- 学科方向：{学科方向}
- 目标读者：{目标读者}
- 时间范围：近 5 年为主，必要时加入经典文献
- 证据偏好：系统综述、指南、随机对照试验、队列研究、真实世界研究

请输出：
1. 研究背景：这个问题为什么重要？
2. 核心概念定义：列出需要先解释的术语。
3. 检索关键词：中文关键词、英文关键词、同义词、MeSH 词建议。
4. PubMed 检索策略：给出 2-3 条不同严格程度的检索式。
5. 综述大纲：一级标题、二级标题、每节要回答的问题。
6. 证据表格：建议提取哪些字段，例如作者、年份、研究设计、样本量、主要结局、局限。
7. 争议点：列出目前可能存在不一致证据的地方。
8. 研究空白：列出值得进一步研究的问题。
9. 写作提醒：哪些结论必须回到原文核查，哪些地方不能过度推断。

要求：
- 不要编造不存在的论文、DOI、PMID 或指南。
- 如果没有原始文献来源，请明确标注“需要检索确认”。
- 语言风格要适合学术综述初稿，而不是营销文案。
```

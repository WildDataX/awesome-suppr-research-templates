# 来源可追溯摘要 Prompt

```text
你是一名科研阅读助手。请基于我提供的论文原文、摘要或表格，生成来源可追溯的结构化摘要。

论文内容：
{粘贴摘要、正文片段或表格}

请输出：
1. 研究问题：这篇论文试图回答什么？
2. 研究设计：RCT、队列、病例对照、横断面、系统综述、机制研究等。
3. 研究对象：样本量、人群、纳入排除标准。
4. 干预/暴露/比较：如果适用。
5. 主要结局：列出主要 endpoint 或 outcome。
6. 关键结果：只总结原文明确支持的结果。
7. 局限性：作者提到的局限和你从方法学上看到的局限。
8. 可引用观点：列出 3-5 条可以进入综述的观点，并标注它们来自摘要、结果、讨论或表格。
9. 不可过度推断：列出哪些结论不能从这篇论文推出。

要求：
- 不要加入原文没有的信息。
- 如果缺少样本量、统计方法或结局定义，请标注“原文片段未提供”。
- 不要生成虚构引用。
```

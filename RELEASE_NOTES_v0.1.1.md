# v0.1.1 Release Notes

This release makes the repository more useful as a real research productivity library and adds the automation foundation for future updates.

## Added Content

- Expanded clinical trial glossary.
- Expanded statistics and methods glossary.
- Added epidemiology terms.
- Added systematic review and Meta-analysis terms.
- Added medical imaging terms.
- Added systematic review protocol prompt.

- Added research-gap analysis prompt.
- Added clinical guideline summary prompt.
- Added diabetes cardiovascular outcomes review example.
- Added oncology immunotherapy review example.
- Added medical manuscript outline template.

## Automation

- `scripts/update_resources.py`: applies reviewed daily/weekly/monthly update tasks.
- `scripts/build_downloads.py`: rebuilds ZIP downloads.
- `scripts/validate_content.py`: checks mojibake, duplicate glossary terms, and missing index targets.
- `scripts/release_version.py`: creates GitHub releases and uploads ZIP assets.

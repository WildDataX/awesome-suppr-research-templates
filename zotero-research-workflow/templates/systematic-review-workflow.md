# Zotero 系统综述工作流

1. 建立 collection：`01-imported`, `02-screen-title-abstract`, `03-full-text`, `04-included`, `05-excluded`。
2. 用 tags 标记排除原因：`exclude/population`, `exclude/intervention`, `exclude/outcome`, `exclude/design`。
3. 对纳入文献添加研究设计和证据等级标签。
4. 用 notes 保存数据提取表和偏倚风险判断。
5. 导出 included collection 用于参考文献管理。

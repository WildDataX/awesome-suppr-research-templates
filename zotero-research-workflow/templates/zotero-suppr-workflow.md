# Zotero + Suppr 工作流

## 1. 收集文献

- 从 PubMed、Google Scholar、期刊官网导入 Zotero。
- 给每篇论文添加 `status/to-read` 标签。

## 2. 初筛

- 阅读标题、摘要和结论。
- 排除不相关文献，添加 `status/excluded`。
- 保留核心文献，添加主题标签。

## 3. 翻译和阅读

- 使用 Suppr Zotero 插件翻译标题、摘要或 PDF。
- 对关键论文使用阅读笔记模板。
- 对结论、统计结果和表格回原文核查。

## 4. 证据矩阵

- 把每篇论文的设计、样本量、主要结局和局限填入 `literature-matrix.csv`。
- 写综述时优先使用证据等级更高、样本量更大、与主题更贴近的论文。

## 5. 综述写作

- 用证据矩阵组织背景、现状、争议和研究空白。
- 用 Suppr 深度研究生成初稿后，人工核查每个引用和结论。

# Zotero 科研工作流模板

这个资料包帮助你把 Zotero 文献管理、论文阅读、翻译和综述整理串起来。

Suppr Zotero 插件：https://github.com/WildDataX/suppr-zotero-plugin

## Files

| 文件 | 用途 |
| --- | --- |
| [templates/zotero-tag-system.md](./templates/zotero-tag-system.md) | Zotero 标签体系 |
| [templates/reading-note-template.md](./templates/reading-note-template.md) | 单篇论文阅读笔记 |
| [templates/literature-matrix.csv](./templates/literature-matrix.csv) | 文献证据矩阵 |
| [templates/zotero-suppr-workflow.md](./templates/zotero-suppr-workflow.md) | Zotero + Suppr 工作流 |

## Recommended Workflow

1. 用 Zotero 收集和分组论文。
2. 用标签标记研究类型、主题、证据等级和阅读状态。
3. 用 Suppr Zotero 插件翻译标题、摘要或文档。
4. 用阅读笔记模板提取研究问题、方法、结果和局限。
5. 用证据矩阵支撑综述或开题报告。

# 学术写作模板包

这个资料包用于把“已经读过文献、已经有结果”的阶段推进到可写作、可投稿、可返修的稿件结构。它不替代作者的研究判断，也不鼓励代写；重点是帮助你把证据、逻辑和表达整理得更清楚。

## Files

| 文件 | 用途 |
| --- | --- |
| [templates/abstract-structured.md](./templates/abstract-structured.md) | 结构式摘要草稿 |
| [templates/introduction-cars.md](./templates/introduction-cars.md) | 引言 CARS 结构 |
| [templates/discussion-limitations.md](./templates/discussion-limitations.md) | 讨论与局限性 |
| [templates/cover-letter.md](./templates/cover-letter.md) | 投稿 cover letter |
| [templates/peer-review-response-letter.md](./templates/peer-review-response-letter.md) | 返修信逐条回复 |
| [templates/ai-writing-trace-checklist.md](./templates/ai-writing-trace-checklist.md) | AI 写作痕迹自查 |
| [templates/claim-evidence-map.csv](./templates/claim-evidence-map.csv) | 论点-证据映射表 |

## Recommended Workflow

1. 先用文献综述包和 Zotero 工作流整理证据。
2. 用 `claim-evidence-map.csv` 为每个核心论点绑定来源。
3. 用摘要、引言和讨论模板生成结构化草稿。
4. 用 AI 写作痕迹自查表检查空泛句、过度承诺和未引用判断。
5. 投稿前人工核对期刊格式、伦理声明、数据可用性声明和参考文献。

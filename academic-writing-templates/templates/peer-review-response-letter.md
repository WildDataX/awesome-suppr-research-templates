# 返修信逐条回复模板

## Response Letter Structure

```text
Dear Editor and Reviewers,

Thank you for the careful evaluation of our manuscript entitled "{title}". We appreciate the constructive comments and have revised the manuscript accordingly.

Below, we provide a point-by-point response. Reviewer comments are shown in italics, followed by our responses and the corresponding manuscript changes.
```

## Point-by-Point Table

| Reviewer comment | Response strategy | Manuscript change | Location |
| --- | --- | --- | --- |
|  | Agree and revise / clarify / justify / respectfully disagree |  | Page, paragraph, line |

## Useful Response Patterns

### Agree And Revise

```text
We agree with the reviewer and have revised the manuscript to clarify {issue}. Specifically, we added {new text/analysis} in {section}.
```

### Clarify Without New Analysis

```text
Thank you for this helpful comment. We have clarified the rationale for {choice} in the Methods section. The revised text now states that {summary}.
```

### Add Sensitivity Analysis

```text
In response to this comment, we conducted an additional sensitivity analysis using {method}. The results were consistent with the primary analysis and are now reported in {section/table}.
```

### Respectfully Disagree

```text
We appreciate the reviewer’s concern. We respectfully believe that {proposed change} may not be appropriate because {reason}. To avoid misunderstanding, we have added a clarification in {section}.
```

## Suppr Prompt

```text
请把下面的审稿意见整理成逐条回复草稿。

要求：
1. 保持礼貌、具体、可执行。
2. 区分“已经修改”“新增分析”“解释原因”“礼貌不同意”。
3. 不要承诺作者没有完成的修改。
4. 每条回复后列出需要作者补充的页码、行号或表格编号。

审稿意见：
{粘贴审稿意见}

已完成修改：
{粘贴修改说明}
```
